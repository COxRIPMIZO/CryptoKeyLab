# 🤝 Contributing to CryptoKeyLab

Thank you for your interest in contributing to CryptoKeyLab! This project is built using **.NET 9, Blazor, and Clean Architecture**. Please follow these steps to ensure a smooth contribution process.

## 🚀 How to Propose Changes

1. **Fork the Repository**: Create your own copy of the repository on your GitHub account.
2. **Clone Locally**: Download your fork to your computer.
3. **Create a Feature Branch**: Work on a separate branch instead of making changes directly to your default branch.
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make and Test Changes**: Ensure your .NET code builds successfully without errors.
5. **Push and Open a PR**: Push your branch to your GitHub fork and submit a Pull Request back to our `master` branch.

## 🛡️ Code Standards
* Use clear commit messages (e.g., `feat: add hashing engine optimization`).
* Follow clean architecture design patterns by keeping domain logic isolated from presentation layers.
