# 🛡️ Security Policy

## Supported Versions

We currently provide security updates for the following versions of CryptoKeyLab:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, **please do not open a public issue.** 

Instead, report it safely by navigating to the **"Security"** tab at the top of this repository page and clicking **"Report a vulnerability"** to submit a private draft advisory. Alternatively, you can contact the maintainer directly via the contact methods listed in the Code of Conduct.
